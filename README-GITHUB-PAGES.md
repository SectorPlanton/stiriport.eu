# Publicare STIRISPORT.EU pe GitHub Pages

1. În repository-ul site-ului, copiază conținutul acestui director în rădăcina branch-ului `main`.
2. Deschide **Settings → Pages** și selectează `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. Păstrează fișierul `CNAME` și configurează înregistrările DNS pentru `stirisport.eu` conform instrucțiunilor GitHub Pages.
4. După publicare, verifică HTTPS, pagina principală, meniul mobil, căutarea, cookie bannerul, paginile de articol și linkurile interne.
5. Trimite `https://stirisport.eu/sitemap.xml` în Google Search Console după ce domeniul este verificat.

## Atenție înainte de lansare

- Articolele importate au date din 18–19 septembrie 2026. Adaugă materiale noi, verificate și datate corect înainte să promovezi site-ul ca actualizat zilnic.
- Scorurile live nu sunt conectate la un furnizor de date în timp real.
- Snapshot-urile vechi de cote și ofertele casino nu sunt afișate ca actuale.
- Sloturile publicitare sunt marcate neactive. AdSense și analytics nu sunt instalate.
- URL-urile de afiliere rămân neconfigurate până când ai aprobări și linkuri oficiale.
- Completează datele reale ale operatorului și datele de contact în paginile legale înainte de lansare și verifică-le pentru situația reală a site-ului.
